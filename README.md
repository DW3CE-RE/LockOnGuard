# Lock-On Guard

Normally, when locking onto a target and guarding, you remain facing whatever direction you
were looking at when you started guarding.

Now you rotate to always be facing your target.

## Installation

1. [Download UE4SS experimental](https://github.com/UE4SS-RE/RE-UE4SS/releases/download/experimental-latest/UE4SS_v3.0.1-1176-g1ba38db4.zip)
2. Open the game folder
   1. Right click the game in your Steam library
   2. Hover over `Manage`
   3. Click `Browse local files`
3. Extract UE4SS to `DW3CE_RE\Binaries\Win64`
4. There should now be a folder named `ue4ss` and a file named `dwmapi.dll` inside of the `Win64` folder
5. Extract the mod folder to `ue4ss\Mods`
6. There should now be a folder called `LockOnGuard` in `DW3CE_RE\Binaries\Win64\ue4ss\Mods`
